# BackupMaster 需求说明（v0.4.0）

## 用户场景与验收标准

| 编号 | 场景 | 可验证的验收标准 |
|---|---|---|
| R-01 | 备份目录 | `backup` 生成单个归档；源目录内输出、已有归档及无匹配条目均报错。 |
| R-02 | 压缩文件 | 重复数据自动用 RLE 缩小；不可压缩数据原样保存；文件恢复后逐字节一致。 |
| R-03 | 浏览归档 | `list` 展示原始大小与引用目标，不必读取普通文件载荷。 |
| R-04 | 校验归档 | `verify` 完整解码并拒绝未知格式、危险路径、异常长度、截断、校验失败和尾随数据。 |
| R-05 | 恢复归档 | `restore` 拒绝非空目标；数据错误时清理本次创建内容；元数据按指定模式处理。 |
| R-06 | 兼容旧版 | v1、v2、v3 仍可列出、校验和恢复；新备份写入 v4。 |

非功能要求：C++17 核心代码分块处理文件，Windows 与 Linux 可构建；无第三方压缩库。
归档校验采用 FNV-1a 64，仅用于意外损坏检测，不提供防篡改保证。
